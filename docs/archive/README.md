# Archive

This folder contains historical investigations, old root-cause writeups, handoff notes, and review snapshots.

Archived docs may describe behavior that has since changed. For current product behavior, use:

- [Current app features](../current/APP_FEATURES_CURRENT.md)
- [Feature status matrix](../current/FEATURE_STATUS_MATRIX.md)
- [Current code anchors](../current/CODE_ANCHORS_CURRENT.md)
- [Automation system overview](../current/AUTOMATION_SYSTEM_OVERVIEW.md)
- [Automation delete status](../current/AUTOMATION_DELETE_STATUS.md)
- [Testing and logs](../current/TESTING_AND_LOGS_CURRENT.md)

## Archive Groups

- `fixes/`: one-off bug investigations and old fix explanations.
- `handoffs/`: previous conversation snapshots and transition notes.
- `research/`: early product/technical research.
- `reviews/`: older implementation reviews, analysis docs, and verification summaries.
